# DEEPKIN — Field Archive (web)

Player-facing wiki and showcase for DEEPKIN, in English (`en/`) and Spanish (`es/`).
Static HTML/CSS/JS: no build tools, no dependencies beyond Python 3 for generation.

## Pages

Home · Story · Classes · Arsenal · Gear · Resources · Bestiary · World · Field Manual · Wiki

The **wiki** (`en/wiki/`, `es/wiki/`, generated by `src/wiki.py`) has one page per item, creature, person, zone, faction, material and quest, plus mechanics pages (experience, death, skills, classes, vehicles with the bike shop and crane, currency, fuel, computers, and since 2026-10-23 party, drones, houses, VDI excavations, contracts, trading & shops, food, reading logs, ammunition & energy weapons, batteries & recharge — `src/wiki_mech.py`; Spanish texts for the Phase 1–7 content in `src/wiki_es_p8.py`), category tables, breadcrumbs and a site-wide search (`/`, index in `<lang>/wiki/search.js`). URLs come from game IDs (`src/slugs.py`). The world map is drawn by depth level (surface, −1 … −4 from each zone's `level`): a depth rail switches levels, vertical passages (lifts, stairs, adits, shafts) are marked on both levels they join and switch on tap. Every level is drawn in the painting's own normalized frame (one SVG viewBox over the art, so a point stays put when the level changes; zoom and pan are kept): each underground map sits where the data puts it (its cell, or its `stack.marker`) and each passage at its data point (`exit_at`, or the lower floor's stack marker); only the Shaft 3 well is fixed in `worldmap.VLINK_AT` (the painted headframe). A passage that falls on a floor's own mark is drawn beside it, offset in screen pixels, so the point itself does not move (2026-10-24); two passages on one point sit side by side, and underground labels take the first free side (below, right, left, above) of their mark. It opens a zone (on its level) or district from `world.html?zone=<id>#map` / `?district=<id>#map`. The build prints the data gaps it finds.

## Generate

```bash
python3 build.py          # rebuild en/, es/ and index.html from data/ + src/
python3 build.py --sync   # first copy fresh game data + icons from ../deepkin
```

- `data/` — snapshot of the game repo: `data/entities/*` (classes, items, npcs, materials, factions, discoveries, vehicles), `starting_region.json`, `world/` (world map, sets, banners, respawn hubs), `dialog/`, `quests/`, and `rules/` (the `.gd` rule files plus `constants.json`; `src/gdconst.py` reads their constants). Retired items are skipped; `planned` items show as *Coming soon*.
- `src/wiki.py`, `src/wiki_i18n.py` — wiki pages and their EN/ES strings (never numbers).
- `assets/models/<item id>.glb` — small 3D item models (≤ 1 MB, 2026-10-13) written by the game's `tools/export_web_models.gd`; an item page with a model shows it in `<model-viewer>` (pinned 3.5.0, lazy; the icon is the poster and the fallback).
- `data/shops/`, `data/houses/`, `data/excavation/` — trader goods and prices, house data and excavation templates (synced); shop data feeds the trading page, item "Bought and sold by" tables and the traders' pages.
- `src/i18n.py` — UI strings, class/creature copy and Spanish item descriptions.
- `src/atlas.py` — the World page's illustrated field atlas (`assets/img/world/atlas_<lang>.svg`, phone variant `_m.svg`): plan + depth cross-section + passage key, generated from `world_map.json` and the transitions in `starting_region.json`. Every mark in the plan sits at its data point (marker, `stack.marker`, the Shaft 3 well from `worldmap.VLINK_AT`) through the same projection as the live map; only labels and passage badges are laid out per sheet (2026-10-24). Floors that share one point (the Outpost and the Threshold under the Shaft 3 well, C-3 floors 2–3) are one pile of plates; four-floor hideouts (Castoff Hideout, The Pump Works) are one stacked plate in the plan and one plate per floor in the cross-section; places come from the data (`worldmap.sites()`: traders in `data/shops/`, the bike shop, the VDI post, the house door, the VDI excavation clearing; hunting grounds from a zone's `hunting` block or a wild/hunting-spot zone with spawn groups). VDI excavation floors are drawn as a ghost bore marked player-made (generated per call-out, not fixed zones). The interactive map shows the same places (hunting and excavation on the continent, traders/bike shop/VDI/house in the Dustline plan, each placed by the district or gate nearest to it in the built city). `src/lore.py` — the World page lore layer (EN/ES).
- `src/story.py` — the story (Spanish original from `DEEPKIN_Historia_ES.html`, plus English translation).
- `src/texts.py` — world regions, controls, first steps, home page copy.
- `build.py` — derived stats use the same formulas as the game server (`shared/gameplay/rpg_rules.gd`, `weapon_skills.gd`, `combat_skills.gd`). Update the constants there if balance changes.

## View

Open `index.html` in a browser (it redirects to your language), or serve the folder:

```bash
python3 -m http.server 8611
```

Deploys as-is to any static host (GitHub Pages, Cloudflare Pages).
